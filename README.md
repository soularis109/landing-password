# Локальний референс dala.craftedbygc.com (Next.js)

Next.js-обгортка, яка віддає завантажену копію сайту для вивчення анімації.
Файли референсу лежать поза репозиторієм: `~/Desktop/dala-reference` (змінити: `DALA_REF_DIR`).

```bash
npm install
npm run dev        # http://localhost:3000
```

У production-збірці роут вимкнено (404). Попередній демо-застосунок: гілка `my-demo`.
